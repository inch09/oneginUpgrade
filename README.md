                                                    Проект "Онегин" 
Суть проекта заключается в сортировке поэмы Александра Сергеевича Пушкина "Евгений Онегин" тремя способами :
1) В алфавитном порядке слева направо, игнорируя все символы, не являющиеся буквенными. Причем, в этой сортировке не различаются заглавные и строчные буквы.
2) В алфавитном порядке справа налево с теми же условиями, что и в первом пункте.
3) Сортировка, предложенная самим Александром Сергеевичем при публикации поэмы. Самая осмысленная, и честно говоря, самая интересная.

Чем интересна каждая из сортировок?
1) Самая скучная и неинтересная
2) Сортировка, в которой соседние строчки рифмуются между собой. Это интересно, весело, но осмысленности нет(((
3) Бессмертная сортировка, изучив которую, вы станете другим человеком.

Теперь поговорим о интересных приемах, использованных при написании этого проекта:
1) Программа читает текст из файла "Eugene_Onegin.txt" и записывает массив символов в динамическую память
2) Этот массив символов обрабатывается и разбивается на отдельные строки
3) Создается массив указателей на строки поэмы и заполняется данными через специальную функцию
4) Теперь эти данные подлежат сортировке, поэтому в рамках этого проекта написан свой quickSort
6) Он совмещается со стандартным qsort из стандартной библиотеки
7) Для этих двух сортировок нужны компараторы(функции которые сравнивают строки)
8) Поэтому написаны компараторы для этих сортировок
9) После сортировок строки печатаются в файл с помощью специальной функции, написанной для этого
10) На выходе в файле получаем три разных текста, которые соответсвуют разным сортировкам
